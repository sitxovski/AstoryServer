# Реестр серверных правок AsdaStory — INDEX

Единое место для ВСЕХ правок/патчей/настроек **серверной** части
(`\\@@ASTORY_SERVER_HOSTNAME@@\h(@@ASTORY_SERVER_HOSTNAME@@_ns)\ASDA\Working_ASDA\v2`). Создан 2026-08-03.

## Правило ведения
- На КАЖДУЮ серверную правку (бинарный патч, конфиг, настройка ОС, доп. процесс) — отдельный
  `.md` в подпапке процесса: `GameServer/`, `NpcServer/`, `ChannelManager/`, `LoginManager/`,
  `DBManager/`, `ItemRelayServer/`, `Indun_GameServer/`, `Indun_NpcServer/`, `_Common/` (межпроцессное / ОС).
- **Записи ДОБАВЛЯЮТСЯ, не переписываются.** Откат оформляется НОВОЙ записью (или сменой поля
  «Статус» существующей на `откачено`/`заменено» + дата`). Историю не затираем.
- Обязательные поля дока: дата; статус; процесс+полный путь файла; тип; ЧТО (адрес+байты
  «было→стало» или ключ=значение); ЗАЧЕМ (симптом→диагноз, ссылка на `Reports/…`); где
  БЭКАП; как ОТКАТИТЬ (пошагово); нужен ли РЕСТАРТ; риски/связанное.
- **Клиентские правки СЮДА НЕ идут** — у них `CHANGELOG_*` и `Reports/`.
- Живой сервер и бэкапы — только на `\\@@ASTORY_SERVER_HOSTNAME@@\...\Working_ASDA\v2` (см. MEMANTO `server-live-path`).
- ★ 22.10.2026 — **инструменты патчей с шарой НЕ работают** (\\@@ASTORY_SERVER_HOSTNAME@@ висит; слово владельца «если шара недоступна — ssh»).
  Сервер = `@@ASTORY_SERVER_ROOT@@\Working_ASDA` по SSH (`Administrator@@@ASTORY_SERVER_LAN_IP@@`, ключ `@@ASTORY_SSH_KEY_NAME@@`). Чтение: `AsdaPatch/tools/srv_mirror.py`
  снимает по SSH (только чтение, FileStream с FileShare.ReadWrite, предел времени на шаг, md5, кэш) образы и таблицы в
  `AsdaPatch/tools/_srv_mirror/`; корень для всех verify_* (AsdaPatch/AsdaSecure/AddonNPC), `run_checks.py`, `inject_import*.py` —
  `AsdaPatch/tools/srv_paths.py` (шара только `ASDA_USE_SMB=1`). `python run_checks.py` сам обновляет зеркало. Выкладка — только
  по SSH по образцу `deploy_p77.py`; старые `deploy_acdb/p29r2/p71p72n18/p74/p75/p76.py`, `restart_stack_p76.py`,
  `data_levelcaps_20261022.py --apply` помечены «устарело» и без `ASDA_USE_SMB=1` отказываются (код 3).
