# Бонус подбора 401 — расхождение памяти GS и базы (дефект оригинала, НЕ исправлен)

- **Дата:** 2026-11-21 (найдено при реверсе А6.3 админ-центра, подтверждено ревизией 52 — `Reports/admin_center/review52_a63_econ_20261121.md`).
- **Процесс:** GameServer.exe (основной, Ch2, Indun — один образ).
- **Статус:** [ОРИГИНАЛ] дефект подтверждён; на dev **недостижим** (параметра 401 нет ни в одной копии SowelCombine). Не чинится, в реестре
  отложенного `Docs/Port/PORT_PENDING_ON_SYSTEMS.md` (21.11.2026, А6.3).

## Что такое 401
`sub_448B20@0x448B20` (`GameServer.c:29799-29839`) — сумма бонус-параметра по 11 надетым слотам: предмет с признаком «надето», тип
`*(byte*)(dword_5F5E98 + 71*(code−20551) + 36) == 3`, пары (id, значение) из записи SowelCombine `+158/+160` (id) и `+162/+164` (значение).
Загрузчик `GameServer.c:65161-65243`: токены **51/52 и 53/54** строки `ItemTable_Info\SowelCombine.txt`. Те же пары дают 53 (опыт) и 93
(штраф смерти). **401 — прибавка к количеству подобранного** (золото и стопочные предметы).

## Где расходится
`CharItemPicking@0x4D43A0`:
- вызовы `sub_448B20(…, 0x191)`: VA 0x4D4E18, 0x4D50B7, 0x4D5545 (`push 191h`);
- пакет в DBManager 2011 (`push 7DBh`): VA 0x4D4E53, 0x4D5100, 0x4D5B66 → `sub_5646C0@0x5646C0`;
- память GS пишется `sub_4D63F0` из `Src` = было + подобранное **без** бонуса (`GameServer.c:84415-84421`, отряд `:84461-84467`), клиенту
  уходит 5013 с тем же `Src`; в пакет 2011 — `v67 + sub_448B20(…, 401)` (`:84437`, отряд `:84484`); стопочные — `:84273-84286`.
- Отряд (дизасм 0x4D50AE…0x4D510A): `mov [ebp-47h], v67` → `call 0x448B20 (…, 0x191)` → `add eax,[ebp-47h]` → `push 45h; push 7DBh; call 0x5646C0`.

База: `Joy1.UPItemPick` — `@Fa=Amount=Amount+@Amount` (относительно) или INSERT новой кучки — бонус ложится в БД. Абсолютной записи
золота из памяти GS в процедурах нет (все обновления золота — относительные).

## Следствие
При ненулевом 401 **база больше памяти GS** на бонус до перезахода / смены сервера, потом бонус «появляется» у игрока. Дюпа и потери нет
(списания относительные). В «Экономике» админ-центра такой бонус ушёл бы в «неучтённое».

## Достижимость
Все три живые копии `@@ASTORY_SERVER_ROOT@@\Working_ASDA\v2\{GameServer,Ch2_GameServer,Indun_GameServer}\ItemTable_Info\SowelCombine.txt`
(10 786 101 б, 10.11.2026): id 401 в токенах 51/53 — 0 строк; в `Donors/GameServer_stock` и `live_orig` — тоже 0. Риск появится, только
если 401 впишут в SowelCombine (например, при заполнении бонусов премиум-вещей, как 07.11 для 53/93).

## Если чинить (не сейчас)
Серверный патч: в ветках золота / стопочных `CharItemPicking` прибавлять бонус и к `Src` (память и 5013), либо не прибавлять к пакету 2011 —
решение владельца (смысл бонуса «+N к подбору»).
