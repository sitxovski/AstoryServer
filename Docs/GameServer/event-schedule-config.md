# GameServer — расписание событий (Lucky/Bonus Hours) — конфиг

- **Дата:** 2026-07-25 (правки бэкапов от 25.07 14:2x–14:5x).
- **Статус:** ✅ ДЕЙСТВУЕТ.
- **Процесс:** GameServer (+ копии Event.dat в Indun_GameServer / NpcServer / Indun_NpcServer).
- **Тип:** конфиг (текст/бинарь расписания событий).

## ЧТО изменено
- `GameServer\Event\GameServerEvent.txt` — таблица бонус-часов расширена с **60 → 360** записей (первая строка = счётчик: было `60`, стало `360`). Формат строки: `год мес день часОт часДо множитель` (напр. `2026 7 25 0 1 1.0`). Заполнено расписание бонус-часов на множество дней. Генерировалось `GameServer\Event\LuckyHours.exe` (от 25.07).
- `GameServer\Event\Event.dat` — сопутствующий бинарь (2200 б), перегенерирован (размер не изменился).
- Копии `Event.dat.bak` также лежат в `Indun_GameServer\Event\`, `NpcServer\Event\`, `Indun_NpcServer\Event\` (25.07 14:54) — те же события для данж/npc-процессов.

## ЗАЧЕМ
Настройка расписания бонусных/«счастливых» часов (множитель опыта/дропа по часам). Не патч бинаря — редактирование игрового конфига событий.

## Бэкапы
- `GameServer\Event\GameServerEvent.txt.bak` (61-строчная версия, до расширения).
- `GameServer\Event\Event.dat.bak`, `Indun_GameServer\Event\Event.dat.bak`, `NpcServer\Event\Event.dat.bak`, `Indun_NpcServer\Event\Event.dat.bak`.

## Как ОТКАТИТЬ
Вернуть `*.bak` поверх рабочих файлов; **рестарт GameServer** (и Indun_GameServer). Расписание читается на старте.

## Риски
Низкие — данные событий. Расписание конечно (до 2026-07-29+): при исчерпании дат бонус-часы перестанут срабатывать, потребуется догенерация `LuckyHours.exe`.
