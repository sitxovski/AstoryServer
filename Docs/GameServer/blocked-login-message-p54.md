Решение владельца 12.10: вход соулмейтом в персонажа заблокированного хозяина — запрет **с сообщением** игроку.

## 1. Что было
P50 (DBManager) при блоке учётки (своей учётки сессии или действующем блоке хозяина персонажа при входе соулмейтом)
отвечал штатной неудачей 2002/2090 `[0] = 0`. GameServer в ветке «CharInfo DB Receive Error»
(`charLogOnRes@0x5277D0`, `CharPortalLogonRes@0x52CF90`) шлёт клиенту 4101 с кодом **5**, эталон клиента
(`game_main.c:5915-5960`) показывает loc 8509 «Подключение прервано: недостаточно данных» — причина игроку непонятна.

## 2. Что стало
- **DBManager, P50**: при отказе ИМЕННО по блоку учётки (причина «учётка заблокирована», код 2) в тело ответа
  2002/2090 кладётся метка: `[0] = 0` (как раньше), `[1..4] = 'P54B'` (`50 35 34 42`), `[5] = 1`. Сток GameServer в
  ветке неудачи читает только `[0]` — без P54 поведение прежнее. Признак отказа по блоку хранится в переменной
  потока (`t_blocked`), сбрасывается перед каждой сверкой. Ключ `[P50_IdentityCheck] BlockedClientCode7=1`
  (0 — метки нет, код 5 как раньше).
- **GameServer, P54**: в двух ветках неудачи `push 5` заменён стабом: метка есть → `push 7`, иначе `push 5`.
  Прочие отказы P50 (IP, сессия, слот, нет учётки) — код 5, как в стоке.
- Код 7 — штатный код оригинала для блока учётки (LoginManager: `UPUserLogin` Flag 5 → 4101/7). Клиент оригинала и порт
  (`AsdaLoginGameMode.cpp` BuildKickText, `AsdaDisconnectPopupSubsystem.cpp`) показывают на код 7 loc **1107**
  «Ты не можешь подключиться: учетная запись заблокирована.». Правка клиента не нужна.
- Журнал P53: в `ac.login_check_refusal` колонки `client_code` / `client_message` показывают, что увидел игрок;
  в `ac.kick_block` кик типом 7 называется «учётная запись заблокирована (P54)».

## 3. Площадки (сток = живой `GameServer.exe` = `Indun_GameServer` `e7b4ac38…`)

| VA | байты стока (6) | функция | тело ответа | возврат |
|---|---|---|---|---|
| `0x00527907` | `6A 05 66 8B 45 08` (`push 5` / `mov ax,[ebp+8]`) | charLogOnRes (4001 → 2002) | `[ebp-0x120]` | `0x0052790D` |
| `0x0052D07A` | `6A 05 66 8B 4D 08` (`push 5` / `mov cx,[ebp+8]`) | CharPortalLogonRes (5058 → 2090) | `[ebp-0x118]` | `0x0052D080` |

Байты обеих площадок сверяются при установке; не сошлось — `[MISMATCH]`, ничего не ставится. Чтение метки — под SEH
(ошибка → код 5).

## 4. Проверка после старта
- GameServer/Indun `PatchLog`: `[OK] P54_BlockedLoginMessage` и строка «P54: отказ P50 по блоку учётки -> 4101 код 7 … площадок 2 из 2».
- DBManager `PatchLog`: в строке P50 «… отказ по блоку -> метка P54 (игроку код 7)=1».
  персонажа — окно «учетная запись заблокирована»; в `ac.v_login_check_readable` строка с `client_code = 7`.

## 5. Откат
- `[P54_BlockedLoginMessage] Enabled=0` (GameServer/Indun `patches.ini`) **или** `[P50_IdentityCheck] BlockedClientCode7=0`
  (DBManager `dbpatch.ini`) + рестарт процесса → снова код 5.
- Полный: `AsdaPatch.dll.bak_20261012_acdb` / `DBPatch.dll.bak_20261012_acdb` на место DLL + рестарт.
