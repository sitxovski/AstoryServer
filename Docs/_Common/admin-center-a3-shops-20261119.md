## Как применяется серверная половина (в этой волне — НЕ применялась)
`python asda_admin.py changeset server-dry N` (на ПК) → `changeset server-apply N --confirm-restart` (только владелец, только
консоль ПК: `restart_stack.py` работает с ПК — SSH к стойке и бот Discord) → объявление в Discord, 3 мин, штатная остановка,
`deploy_changeset.py --apply`, паритет Ch2, старт → `deploy_changeset.py --check-started`. Сервер раньше клиента — только с
`--unsynced-ok`. Строка сюда и в changelog дописывается автоматически.
