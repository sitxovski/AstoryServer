# N24 — нет лута с низких мобов и в отряде с разбросом уровней (AddonNPC, Config 15, 06.11.2026, сессия pet-hatch-summon)

**Статус:** собрано, стенд и проверки зелёные, **не выложено** (выкладка — координатор по слову владельца, `deploy_n24.py`).
[ИСПРАВЛЕНИЕ] — отклонение от оригинала по решению владельца.

## Как было
Лут считает NpcServer: `CMonster::Process_MonsterDead` = `sub_437A30` (`RE/ida/npc_work/NpcServer.exe.c:41052`). GameServer `recvBattleServerFromItemDrop@0x4C9370` только принимает готовый пакет 8303. Лут разыгрывается один раз на владельца (первый по угрозе; при флаге монстра +30958&2 — убийца). Проверки уровней в нём нет ни в одной версии образа; шанс `sub_42E3A0` = ставка × (1 + бонусы владельца + событие).

## Правило
Участник годен, если `уровень игрока − уровень моба < LevelGap (7)` и разброс уровней его отряда `< SpreadLimit (10)`.
- Владелец годен — пакет как есть.
- Иначе владелец — первый по угрозе годный из списка (порядок стока: больше урона, при равенстве меньше поле +4).
- Годных нет — пакета 8303 нет: ни предметов, ни денег, ни мирового дропа.

Боссы без исключений. Бонус шанса посчитан по исходному владельцу: розыгрыш и ход ГСЧ стока не меняются. Блок заданий +31210 идёт после площадки и не меняется. Опыт не меняется.

Разброс: `SpreadWholeParty=1` — все члены отряда, известные этому NpcServer (номер отряда +30470 в слоте; при выходе слот сбрасывается: `sub_421BD0` → `sub_426AB0` → `sub_42C530`), включая не бивших. `0` — только записи угрозы. Пустой слот (игрок вышел, уровень 0) — не участник. Отряд из другого GameServer (канала) этот NpcServer не видит. Если отряд негоден, а на моба бил посторонний годный игрок, лут достаётся ему.

## Опыт (не менялся; разобрано для сравнения)
1. NpcServer, каждая запись угрозы: разница ≤ 6, иначе запись пропускается; при разнице больше 1 минус 10% за уровень.
2. GameServer `sub_4C7650` (8306): разброс среди записей пакета; 10 и больше — опыта нет никому. Проверка 20 клеток идёт после, на разброс не влияет.
3. `sub_4C7C70`: проверка уровня каждого участника.

Дыры опыта (стенд `gsexp`): лв60 + лв5 на низком мобе — лв60 отсеян на шаге 1, разброс 0, лв5 опыт получает; не бивший член отряда в разброс не входит. Дефект стока: минимум разброса стартует с 59 (0x4C77E7), отряд с максимальным уровнем 69 и выше опыта не получает никогда.
