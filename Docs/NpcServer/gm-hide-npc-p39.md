## Что было в оригинале

GameServer `Send_HideCommand@0x54E970` → `sub_4C6C50` шлёт 8115/8116 (7 б: `[0]=1`,
`[1..4]` UserIndex, `[5..6]` номер игрока). NpcServer: `case 0x1FB3/0x1FB4` →
`Process_PlayerAddState@0x45A0C0` / `Process_PlayerSubState@0x45A030` → бит 2 в `+30292`
записи игрока. Бит читают только две ветки поиска первого агрессора — остальной ИИ его не видит.

## Выкладка

1. Остановить `NpcServer` и `Indun_NpcServer` (GameServer можно не трогать).
2. В ОБЕИХ папках: `AddonNPC.dll` → `AddonNPC.dll.bak_pre_p39_20260927`.
3. Скопировать новую `AddonNPC.dll` (MD5 `227356712b0cdaacc3901383a3f582b3`) в обе папки.
4. Запустить. В `Log\Log_Patch\PatchLog_<дата>.txt` обеих папок ждать:
   строку «скрытый оператор (8115) невидим для монстров: снятие цели ВКЛ, …», затем
   `[OK] N11_GmHideNpc`, итог «применено 10, пропущено 1, ошибок 0» (строк `MISMATCH` быть не должно).
   В `ConfigSet\patches.ini` появится секция `[N11_GmHideNpc]`.
5. Живой тест под **операторской** учёткой (`UserIndex` 0…5000) — `Reports/owner_0927/gm_hide_npc.md` §7.

## Откат

- мягкий: `[N11_GmHideNpc] Enabled=0` в `ConfigSet\patches.ini` обеих папок → рестарт NpcServer;
- частичный: выключить нужный ключ из списка выше;
- полный: вернуть `AddonNPC.dll.bak_pre_p39_20260927` → рестарт.

## N12_GmHideHate — доводка P39 (2026-09-27, вечер), **СОБРАН, НЕ УСТАНОВЛЕН**

Закрывает СРЕДН-1 ревизии: угроза к скрытому чистилась только в момент 8115 и могла вернуться.
Разбор: `Reports/owner_0927/gm_hide_npc_2.md`. Исходник: `AstoryServer/Patches/AddonNPC/src/patches/n12_gm_hide_hate.cpp`.
